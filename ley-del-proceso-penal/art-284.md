# Artículo 284
CAPÍTULO X
DICTAMEN PERICIAL
1. Se dispone el dictamen pericial cuando para conocer, verificar, apreciar o lograr la explicación de un hecho, sus circunstancias, o el examen de personas, objetos o cualquier elemento de prueba de importancia para el proceso, se requieran conocimientos científicos, artísticos, técnicos o prácticos.
2. Cuando los conocimientos que se requieran sean comunes no es necesaria la práctica del peritaje.
